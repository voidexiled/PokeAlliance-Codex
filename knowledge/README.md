# Alliance Codex Knowledge Base

This directory stores human-readable research governance and evidence notes. Machine-readable source, staging and normalized datasets live under `data/`.

## Status vocabulary

- `confirmed`: direct, current and sufficiently authoritative evidence.
- `supported`: credible evidence exists but needs stronger/current corroboration.
- `inferred`: a documented conclusion from evidence, never presented as fact without qualification.
- `unknown`: required information is unavailable.
- `conflicted`: credible sources disagree or scopes cannot yet be reconciled.
- `deprecated`: previously used conclusion no longer applies.

Authority, confidence and freshness are separate. A source can be official but stale, community-authored but reproducible, or historical and useful only for hypotheses.

## Research rule

Do not copy a value into normalized data without an evidence reference. Do not use general Pokémon behavior to fill a PokeAlliance gap.
