# Source Registry

The machine-readable registry is [`data/research/sources.json`](../../data/research/sources.json). This folder holds source-specific notes that cannot be expressed cleanly in the registry.

Initial classification is provisional. In particular, the main website calls itself a community fansite while the wiki says it is maintained by administrators. This supports a first-party/administrator relationship hypothesis, not an unqualified legal ownership claim.

## Authority classes

- `first_party`: controlled by or explicitly connected to current PokeAlliance administration.
- `official_candidate`: presents first-party signals pending stronger verification.
- `community`: player-maintained material.
- `historical`: code/content not assumed to describe the current game.
- `discovery_only`: useful for leads but unsuitable as factual evidence by itself.
