# Localization Glossary

Canonical game terms and Alliance Codex UI labels. Game terms keep their canonical form in every locale; UI labels are translated.

| Canonical term | Type | Translate? | Spanish presentation | English presentation |
|---|---|---:|---|---|
| PokeAlliance | product/game name | no | PokeAlliance | PokeAlliance |
| Alliance Codex | product name | no | Alliance Codex | Alliance Codex |
| Shiny | variant marker | no | Shiny | Shiny |
| Mega | variant marker | no | Mega | Mega |
| Boost | game system term | no | Boost | Boost |
| Helds | game system/category term | no | Helds | Helds |
| Stars | game system term | no | Stars | Stars |
| Hazard | game system term | no | Hazard | Hazard |
| Pokédex | common product category | UI-localizable with care | Pokédex | Pokédex |
| Required Level | UI label | yes | Nivel requerido | Required level |
| Recommended rotation | UI/editorial label | yes | Rotación recomendada | Recommended rotation |
| Where to find it | UI label | yes | Dónde encontrarlo | Where to find it |

Game entities such as Pokémon, moves, items, NPCs, quests and locations are added with their canonical in-game name. Search aliases never replace display names.
